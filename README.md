# 🎮 Simon Says Game

An interactive memory game built using HTML, CSS, and JavaScript.

The game generates a random color sequence, and the player must repeat the pattern correctly to advance to the next level.

## 🚀 Features
- Random sequence generation
- Level progression system
- Game over detection
- Interactive button animations
- Sound effects (if added)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (Vanilla JS)

## 🧠 Concepts Used
- DOM Manipulation
- Event Listeners
- setTimeout for sequence animation
- Array handling
- Game state management
